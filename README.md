# Abbox

Abbox is an open-source compiler that analyzes application source code and produces a framework-independent Product IR describing how the product works.

## Status

`compile(projectPath)` reads a local project and returns Product IR for screens found in static TanStack file routes. Navigation, `abbox.json`, and the `abbox compile` command are not available yet.

See [docs/IR.md](docs/IR.md).

## v0 target

The first compiler version will read a local TypeScript/React application that uses TanStack Start or TanStack Router, including applications generated by Lovable, and write `abbox.json`.

v0 analysis is limited to screens/routes and the navigation between them:

- Screens identified from routes such as `/`, `/login`, `/dashboard`, and `/projects/$projectId`
- `<Link to="...">`
- `navigate({ to: "..." })`
- `redirect({ to: "..." })`

Framework-specific interpretation stays in compiler code. The Product IR does not expose framework or parser types.

## Development

Node.js `>=22.12` is required.

```bash
npm test
npm run lint
npm run build
```
